# ValerisBank edit summary

- Fund Wallet now has four funding methods: Bank Transfer, Card, Wallet, Crypto.
- Funding method is sent to and validated by the server.
- Withdrawal processing sequence is now 10%, 20%, 30%, 40%, 50%, 60%, 70%.
- Withdrawal status details use professional label/value spacing for Amount, Bank, Recipient, Account Number/IBAN, Mobile and Email.
- Added responsive mobile rules to prevent horizontal page swinging/overflow and improve cards, forms, modals and tables.
- Funding/withdrawal remain demo/simulation features; no real payment is initiated.
